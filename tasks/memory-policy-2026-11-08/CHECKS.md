# Проверка документации

Проверить сохранность исходного текста (кроме явно уточнённого запрета merge), отсутствие файлов вне согласованного списка, корректность JSON/JSONL, существование новых локальных ссылок и GitHub readback. Полный локальный checkout/продуктовые тесты не выполнялись; доступный CI точного head проверяется в PR. Это не проверка внешних систем. Основание и ограничения: LOG.md.
