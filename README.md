# Film Agent — адаптивная локальная фотолаборатория

Обрабатывает **оригинальные пиксели**, не генерирует людей и предметы заново. Два семейства визуальных профилей: контрастная **чёрно-белая «120»** с выразительным зерном и цветная **Kodak 35 мм** с более тонким зерном. Исходные файлы никогда не изменяются.

## Установка

Python 3.10+:

```bash
python -m venv .venv
# Windows PowerShell: .venv\Scripts\Activate.ps1
# Linux/macOS: source .venv/bin/activate
pip install -e '.[all,dev]'
```

Если нужен только JPG/PNG/TIFF/WebP и CLI: `pip install -e .`.
Для RAW нужен `pip install -e '.[raw]'`, для HEIC `pip install -e '.[heic]'`, для браузерного интерфейса `pip install -e '.[web]'`.

## Использование

```bash
# Запустить интерфейс в браузере (локальный Gradio, без внешнего API)
film-agent-web

# Одно фото, ISO берём из EXIF, если есть
film-agent ./photos/test.jpg --style hp5-120 -o ./output/test-hp5.jpg --report

# Плёночная Kodak, немного меньше зерна
film-agent ./photos/test.dng --style portra-400 --grain 0.7 -o ./output/portra.jpg

# Пакет целой папки с вложенными каталогами
film-agent ./photos --style trix-120 -o ./output --report

# Для художественно тёплого освещения можно отключить автоматическую коррекцию
film-agent ./photos/test.jpg --style gold-200 --no-auto -o ./output/gold.jpg
```

| Название в CLI | Плёнка | Визуальная идея |
|---|---|---|
| `hp5-120` | Ilford HP5+ 120 | мягкое ч/б, крупное зерно |
| `trix-120` | Kodak Tri-X 120 pushed | контрастное ч/б, крупное зерно |
| `portra-400` | Kodak Portra 400 35 мм | мягкая кожа, деликатное зерно |
| `gold-200` | Kodak Gold 200 35 мм | тёплый цвет и лёгкое зерно |
| `ektar-100` | Kodak Ektar 100 35 мм | насыщенные цвета, мелкое зерно |

Доступны `--strength 0..2`, `--grain 0..3`, `--seed`, `--iso`, `--no-auto`, `--report`.

## Что автоматизируется

1. Читается EXIF ISO (или метаданные поддерживаемого RAW). Входное изображение поворачивается по EXIF; ICC-профиль переводится в sRGB, если это возможно.
2. По уменьшенной копии измеряются светлота, распределение теней/светов и грубая оценка шума. Из малонасыщенных полутонов осторожно оценивается цветовой сдвиг; **не применяется агрессивный автоматический WB**, чтобы сохранить свет сцены.
3. Корректируется экспозиция с защитой светов; при высоком ISO аккуратно подавляется цифровой шум перед добавлением плёночного зерна.
4. Применяется профиль кривой, контраста и цвета, виньетка и зерно с воспроизводимым `seed`.
5. При `--report` рядом с результатом записывается JSON с измерениями и применёнными параметрами (без координат/GPS). Метаданные EXIF исходника в выходное фото не копируются.

**Ограничения:** это настраиваемые авторские стили, а не физически точные профили Kodak/Ilford или обученный VLM-ретушёр. При отсутствии нейтральных областей баланс белого не восстанавливается принудительно. Шумы, пересветы и сильно недоэкспонированные участки не всегда можно исправить; проверяйте результат визуально. Поддержка конкретного RAW зависит от LibRaw/rawpy. Нет ни удалённого AI, ни передачи фотографий третьим лицам.

## Архитектура и дальнейшее развитие

`film_agent/core.py` — анализ, цветовые профили и рендеринг, `film_agent/cli.py` — пакетная обработка, `film_agent/web.py` — локальный UI. Композиция независима от ComfyUI: позже этот процессор можно завернуть в ComfyUI custom node без загрузки моделей. Следующий этап — эталонные фотографии для настройки плёнок и ручное сравнение в условиях разного света/ISO. Профили пока визуальные интерпретации: корректнее оценить их на реальных RAW/JPEG и сопоставить с плёночными референсами.

## ComfyUI (необязательно)

В репозитории также есть **кастомная нода** `Film Agent · Adaptive Film Look`, которой можно подключить уже готовый workflow ComfyUI. Это не Stable Diffusion и не генеративная img2img-перерисовка. Нода обрабатывает входной `IMAGE` и возвращает `IMAGE`, поддерживает батчи.

1. Поместите этот репозиторий в `ComfyUI/custom_nodes/miniature-doodle-photo` (например, через `git clone`).
2. В активном Python-окружении **самого ComfyUI** выполните `pip install -e ./custom_nodes/miniature-doodle-photo` (относительно корня ComfyUI).
3. Перезапустите ComfyUI; соедините `Load Image → Film Agent · Adaptive Film Look → Save Image`.
4. Для изображений с EXIF ISO в ComfyUI используйте необязательный параметр `iso` вручную; стандартный IMAGE-тензор не передаёт EXIF. Для автоматического чтения EXIF/RAW используйте CLI или веб-интерфейс.

**Проверка ComfyUI-совместимости на реальной установке не проводилась**: нужен запущенный экземпляр ComfyUI с PyTorch.
